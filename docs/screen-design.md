# 画面設計：RaiseTechSNS（仮称）

[← 要件定義書に戻る](requirements.md)

## 画面一覧

- S01 ログイン画面：メールアドレス・パスワードでログインする。未ログイン時の起点となる画面
- S02 新規登録画面：ユーザー名・メールアドレス・パスワードで会員登録する
- S03 タイムライン画面：「全体」「フォロー中」を切り替えて投稿を一覧表示し、投稿フォームから新規投稿できる、ログイン後のメイン画面
- S04 投稿詳細画面：1件の投稿とそのコメント一覧を表示し、コメントを投稿できる
- S05 プロフィール画面：利用者のアイコン・自己紹介・投稿一覧、フォロー中・フォロワー数を表示し、他の利用者の場合はフォロー・フォロー解除ができる
- S06 プロフィール編集画面：自分のアイコン・自己紹介を編集する
- S07 ユーザー検索画面：ユーザー名・表示名で他の利用者を検索する

## 画面遷移

- ログイン画面 ⇔ 新規登録画面（未ログイン時に相互に遷移可能）
- ログイン画面 → タイムライン画面（ログイン成功時）
- 新規登録画面 → タイムライン画面（登録成功時）
- タイムライン画面 → 投稿詳細画面（投稿をクリック）
- タイムライン画面 → プロフィール画面（利用者名・アイコンをクリック）
- タイムライン画面 → ユーザー検索画面（検索リンクをクリック）
- 投稿詳細画面 → プロフィール画面（投稿者名・アイコンをクリック）
- プロフィール画面 → 投稿詳細画面（投稿をクリック）
- プロフィール画面（自分） → プロフィール編集画面（編集ボタンをクリック）
- プロフィール編集画面 → プロフィール画面（保存・キャンセル操作後）
- ユーザー検索画面 → プロフィール画面（検索結果の利用者をクリック）
- タイムライン画面・投稿詳細画面・プロフィール画面 → ログイン画面（ログアウト操作）

## 各画面のワイヤーフレーム

### ログイン画面

```
+--------------------------------+
|         RaiseTechSNS            |
+--------------------------------+
|                                 |
|  メールアドレス                  |
|  [_________________________]   |
|                                 |
|  パスワード                     |
|  [_________________________]   |
|                                 |
|           [ ログイン ]           |
|                                 |
|  アカウントをお持ちでない方は     |
|  [新規登録はこちら]              |
+--------------------------------+
```

### 新規登録画面

```
+--------------------------------+
|         新規登録                |
+--------------------------------+
|  ユーザー名                     |
|  [_________________________]   |
|                                 |
|  メールアドレス                  |
|  [_________________________]   |
|                                 |
|  パスワード                     |
|  [_________________________]   |
|                                 |
|           [ 登録する ]           |
|                                 |
|  [ログイン画面に戻る]            |
+--------------------------------+
```

### タイムライン画面

```
+------------------------------------------------------+
| RaiseTechSNS          [検索] [プロフィール] [ログアウト] |
+------------------------------------------------------+
| [アイコン] 今何してる？（280文字まで）                     |
| [_______________________________________]            |
| [画像を選択（最大4枚）]                     [投稿]        |
+------------------------------------------------------+
| [ 全体 ]   フォロー中                                    |
+------------------------------------------------------+
| [アイコン] ユーザーA                2026-08-10 [編集][削除] |
| 投稿本文がここに表示される                              |
| [画像1][画像2][画像3][画像4]                            |
| ♥ いいね 3     💬 コメント 1                            |
+------------------------------------------------------+
| [アイコン] ユーザーB                        2026-08-09  |
| 投稿本文がここに表示される                              |
| ♥ いいね 0     💬 コメント 0                            |
+------------------------------------------------------+
|         （以下、フォロー中の利用者の投稿が新しい順に続く） |
+------------------------------------------------------+
```

- 「全体」「フォロー中」の2つのタブを持つ。「全体」は全利用者の投稿、「フォロー中」はフォロー中の利用者（および自分自身）の投稿のみを、それぞれ新しい順に表示する
- 未フォローの利用者の投稿は「全体」タブでのみ表示され、「フォロー中」タブには表示されない
- 各投稿に、投稿者のアイコン・名前・投稿日時・本文・（あれば）画像（最大4枚、並べて表示）・いいね数・コメント数を表示する
- 自分の投稿には[編集][削除]を表示する（他の利用者の投稿には表示しない）。[編集]を押すと投稿フォームと同じ形式でテキスト・画像を書き換えられる。[削除]を押すと確認のうえ投稿を削除する
- いいねボタンは、自分がいいね済みの場合は見た目を変える（塗りつぶし等）
- 投稿をクリックすると投稿詳細画面に遷移する
- 投稿者のアイコン・名前をクリックするとプロフィール画面に遷移する
- ヘッダーの[検索]をクリックするとユーザー検索画面に遷移する

### 投稿詳細画面

```
+------------------------------------------------------+
| ← タイムラインに戻る                                    |
+------------------------------------------------------+
| [アイコン] ユーザーA                2026-08-10 [編集][削除] |
| 投稿本文がここに表示される                              |
| [画像1][画像2][画像3][画像4]                            |
| ♥ いいね 3     💬 コメント 1                            |
+------------------------------------------------------+
| コメント                                                |
|  [アイコン] ユーザーC   コメント本文がここに表示される      |
+------------------------------------------------------+
| [アイコン] コメントを入力                                |
| [_______________________________________]            |
|                                        [コメントする]    |
+------------------------------------------------------+
```

- [編集][削除]は自分の投稿の場合のみ表示する（タイムライン画面と同様）

### プロフィール画面

```
+------------------------------------------------------+
| ← タイムラインに戻る                                    |
+------------------------------------------------------+
| [アイコン]  ユーザーA                                    |
|             自己紹介がここに表示される                    |
|             フォロー中 12   フォロワー 8                  |
|             [ フォローする ]  ※自分の場合は[プロフィールを編集] |
+------------------------------------------------------+
| ユーザーAの投稿                                         |
+------------------------------------------------------+
| [アイコン] ユーザーA                        2026-08-10  |
| 投稿本文がここに表示される                              |
| ♥ いいね 3     💬 コメント 1                            |
+------------------------------------------------------+
```

- フォローボタンは、自分以外の利用者のプロフィール画面にのみ表示する。既にフォロー済みの場合は「フォロー中」（押すと解除）と表示する
- 自分自身のプロフィール画面にはフォローボタンの代わりに[プロフィールを編集]ボタンを表示する

### プロフィール編集画面

```
+--------------------------------+
|  プロフィールを編集              |
+--------------------------------+
|  アイコン画像                   |
|  [アイコン]  [画像を選択]        |
|                                 |
|  自己紹介（160文字まで）          |
|  [_________________________]   |
|  [_________________________]   |
|                                 |
|           [キャンセル] [保存]    |
+--------------------------------+
```

- 自己紹介・アイコン画像を変更できる。ユーザー名・メールアドレスはこの画面では変更しない
- [保存]を押すとプロフィール画面に戻り、変更内容が反映される。[キャンセル]を押すと変更を破棄してプロフィール画面に戻る

### ユーザー検索画面

```
+--------------------------------+
|  ← タイムラインに戻る            |
+--------------------------------+
|  [___________________] [検索]   |
+--------------------------------+
|  [アイコン] ユーザーA            |
|  [アイコン] ユーザーAbc          |
+--------------------------------+
```

- ユーザー名または表示名の一部を入力して検索する
- 検索結果は一覧表示され、クリックするとそのプロフィール画面に遷移する
- 該当する利用者がいない場合はその旨を表示する
