# RaiseTechSNS 静的プロトタイプモック

[要件定義書](../docs/requirements.md)・[機能要件](../docs/functional-requirements.md)・[画面設計](../docs/screen-design.md)に基づいて作成した、動作イメージ確認用のプロトタイプです。

**これは学習用の使い捨てモックであり、本実装（`../backend/`・`../frontend/`）のソースコードではありません。** バックエンド・データベースを一切使わず、HTML・CSS・JavaScriptのみで動作します。

## 開き方

`index.html` をブラウザ（Chrome等）でダブルクリックして直接開くだけで動作します。ビルドやサーバーの起動は不要です。

```sh
open index.html
```

うまく表示されない場合は、簡易HTTPサーバー経由で開くこともできます。

```sh
npx serve .
# または
python3 -m http.server 8000
```

## できること

- ログイン・新規登録・ログアウト（F-1）
- タイムライン表示（全体／フォロー中の切り替え、いいね数・コメント数表示）（F-2）
- 投稿の作成・編集・削除、画像添付（最大4枚）（F-3）
- コメントの投稿・一覧表示・削除（F-4）
- いいねの登録・解除（F-5）
- フォロー・フォロー解除、フォロー中／フォロワーの一覧・人数表示（F-6）
- プロフィールの表示・編集（アイコン・自己紹介）（F-7）
- ユーザー名・表示名でのユーザー検索（F-8）

## 使い方のヒント

- ログイン画面に、あらかじめ用意したデモアカウント一覧があります。「このアカウントでログインする」ボタンでワンクリックでログインできます（パスワードは全アカウント共通で `password123`）
- デモアカウントはフォロー関係・いいね・コメントの状態があえて非対称に設定してあります。ユーザーを切り替えながら操作すると、「フォロー中タブの見え方の違い」「いいね済み／未済みの表示」「自分の投稿にだけ編集・削除ボタンが出ること」などを一通り確認できます
- ヘッダーの「デモデータをリセット」を押すと、操作した内容をすべて破棄して初期状態（シードデータ）に戻せます
- 画像の添付は、実際のファイル選択・プレビューを再現していますが、保存先はブラウザの`localStorage`のみです（本実装ではAmazon S3に保存する設計です）
- 操作した内容（投稿・コメント・いいね・フォロー等）は`localStorage`に保存されるため、ブラウザをリロードしても消えません。別のブラウザ・別のPCとはデータを共有しません

## 構成

```
prototype/
├── index.html          # エントリポイント（ハッシュルーティングでSPA的に画面遷移）
├── css/style.css        # 共通スタイル
└── js/
    ├── utils.js           # 汎用ヘルパー（アバター生成、日付整形等）
    ├── seed.js             # デモ用の初期データ
    ├── state.js             # 疑似バックエンドAPI（localStorage永続化）
    ├── router.js             # ハッシュルーター
    ├── components/           # 複数画面で共用するUI部品
    └── views/                 # 画面ごとのビュー（S01〜S07に対応）
```

## 技術的な制約・注意点

- `<script type="module">`（ESモジュール）や`fetch()`は使っていません。`index.html`をブラウザで直接開く（`file://`）と、これらはCORSエラーで動作しないためです。すべて`<script src="...">`の読み込み順に依存したクラシックスクリプトとして実装しています
- 画像アセット（アバター・投稿画像）は一切用意していません。実行時に生成するSVGのプレースホルダーを使っています
- ログインのパスワード検証は本物ではありません（平文比較のモックです）。本実装ではSpring Security + JWT、パスワードはBCryptハッシュ化を予定しています（[基本設計書](../docs/basic-design.md)参照）
