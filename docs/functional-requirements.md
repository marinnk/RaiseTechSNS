# 機能要件：RaiseTechSNS（仮称）

[← 要件定義書に戻る](requirements.md)

## 機能一覧

### F-1 ログイン機能

1. 会員登録  
   ユーザー名・メールアドレス・パスワードを入力して新規登録する
2. ログイン  
   メールアドレスとパスワードで認証し、ログインする
3. ログアウト  
   ログイン状態を終了する

### F-2 タイムライン機能

1. タイムライン表示（全体）  
   全利用者の投稿を、新しい順に一覧表示する
2. タイムライン表示（フォロー中）  
   フォロー中の利用者（および自分自身）の投稿のみを、新しい順に一覧表示する
3. 表示切り替え  
   「全体」「フォロー中」をタブ等で切り替えられる
4. いいね数・コメント数の表示  
   各投稿に、その投稿に付いているいいね数・コメント数を表示する

### F-3 投稿機能

1. 投稿作成  
   テキスト（280文字まで）と、任意で画像（最大4枚）を入力して投稿する
2. 投稿編集  
   自分の投稿のテキスト・画像を編集する
3. 投稿削除  
   自分の投稿を削除する
4. 画像表示  
   タイムライン・投稿詳細画面で、添付された画像を表示する

### F-4 コメント機能

1. コメント投稿  
   ログイン中の利用者は、自分の投稿だけでなく他の利用者の投稿にもコメントできる
2. コメント一覧表示  
   投稿詳細画面で、その投稿に付いたコメントを一覧表示する
3. コメント削除  
   自分が投稿したコメントを削除する

### F-5 いいね機能

1. いいね登録  
   ログイン中の利用者は、自分の投稿だけでなく他の利用者の投稿にもいいねできる。1つの投稿につき、1人1回まで
2. いいね解除  
   一度付けたいいねを取り消す
3. いいね状態の表示  
   自分がいいね済みかどうかがひと目でわかるように表示する（ボタンの見た目を変える等）

### F-6 フォロー機能

1. フォロー  
   他の利用者をフォローする。フォローすると、その利用者の投稿がタイムラインの「フォロー中」に表示されるようになる（「全体」には元々表示されている）
2. フォロー解除  
   フォローを解除する。解除すると、その利用者の投稿はタイムラインの「フォロー中」に表示されなくなる
3. フォロー中・フォロワーの一覧表示  
   プロフィール画面で、フォロー中の利用者・フォロワーの一覧と人数を表示する

### F-7 プロフィール機能

1. プロフィール表示  
   利用者のアイコン・自己紹介・投稿一覧・フォロー中/フォロワー数を表示する
2. プロフィール編集  
   自分のアイコン・自己紹介（160文字まで）を編集する

### F-8 ユーザー検索機能

1. ユーザー検索  
   ユーザー名または表示名の一部を入力して、該当する利用者を検索する
2. 検索結果表示  
   検索結果を一覧表示する。一覧から選ぶとそのプロフィール画面に遷移する

※ 本バージョンは最小限の機能に絞る。おすすめユーザーの表示、非公開アカウント、ブロック機能、投稿内容の検索などは対象外とし、余力があれば次バージョン以降で検討する。

## ユースケース

アクターは「ログイン利用者」（未ログイン利用者は主要機能を使えないため区別する）。

### UC01：会員登録する

**アクター**  
未ログイン利用者

**事前条件**  
アプリにアクセスしている

**基本フロー**  
1. 利用者が新規登録画面を開く
2. ユーザー名・メールアドレス・パスワードを入力し、登録操作を行う
3. システムは入力内容を検証し、利用者情報をDBに保存する
4. システムはログイン状態にして、タイムライン画面に遷移する

**事後条件**  
利用者アカウントが作成され、ログイン状態になっている

**例外フロー**  
メールアドレスが登録済み、または入力内容が不正な場合はエラーを表示し、登録を行わない

### UC02：ログインする

**アクター**  
未ログイン利用者

**事前条件**  
利用者アカウントが登録済みである

**基本フロー**  
1. 利用者がログイン画面でメールアドレス・パスワードを入力する
2. システムは入力内容を認証する
3. 認証に成功した場合、ログイン状態にしてタイムライン画面に遷移する

**事後条件**  
ログイン状態になっている

**例外フロー**  
メールアドレスまたはパスワードが誤っている場合はエラーを表示し、ログインしない

### UC03：投稿する

**アクター**  
ログイン利用者

**事前条件**  
ログイン済みである

**基本フロー**  
1. 利用者がタイムライン画面、または自分のプロフィール画面の投稿フォームにテキスト（280文字まで）を入力し、任意で画像（最大4枚）を添付する
2. 投稿操作を行う
3. システムは投稿をDBに保存し、投稿元の画面（タイムラインまたはプロフィール）の一覧の先頭に表示する

**事後条件**  
新しい投稿が投稿元の画面の一覧に追加されている

**例外フロー**  
テキストが未入力・文字数超過、または画像の枚数・形式・サイズが条件を満たさない場合は投稿しない

### UC04：他人の投稿にいいねする

**アクター**  
ログイン利用者

**事前条件**  
いいね対象の投稿が存在する

**基本フロー**  
1. 利用者が投稿のいいねボタンを押す
2. システムはいいねをDBに保存し、その投稿のいいね数を1増やして表示する

**事後条件**  
投稿のいいね数が更新されている

**例外フロー**  
既にいいね済みの場合、ボタンを押すといいねを取り消し、いいね数を1減らす

### UC05：他人の投稿にコメントする

**アクター**  
ログイン利用者

**事前条件**  
コメント対象の投稿が存在する

**基本フロー**  
1. 利用者が投稿詳細画面を開き、コメントを入力する
2. コメント投稿操作を行う
3. システムはコメントをDBに保存し、コメント一覧に追加する。投稿のコメント数を1増やして表示する

**事後条件**  
コメントが投稿に追加され、コメント数が更新されている

**例外フロー**  
コメントが未入力の場合は投稿しない

### UC06：利用者をフォローする

**アクター**  
ログイン利用者

**事前条件**  
フォロー対象の利用者が存在し、自分自身ではない

**基本フロー**  
1. 利用者がプロフィール画面等でフォローボタンを押す
2. システムはフォロー関係をDBに保存する
3. 以降、フォロー対象の投稿が自分のタイムラインに表示されるようになる

**事後条件**  
フォロー関係が成立し、対象利用者の投稿がタイムラインに表示される

**例外フロー**  
既にフォロー済みの場合、ボタンを押すとフォローを解除する

### UC07：投稿を編集する

**アクター**  
ログイン利用者

**事前条件**  
編集対象が自分の投稿である

**基本フロー**  
1. 利用者が自分の投稿の編集ボタンを押す
2. 編集フォームに既存のテキスト・画像が入力済みで表示される
3. 内容を変更し、保存操作を行う
4. システムは投稿の内容をDBに反映する

**事後条件**  
投稿の内容が更新されている

**例外フロー**  
テキストが未入力・文字数超過、または画像の枚数・形式・サイズが条件を満たさない場合は保存しない。キャンセル操作をした場合は変更を破棄する

### UC08：自分のプロフィールを編集する

**アクター**  
ログイン利用者

**事前条件**  
ログイン済みである

**基本フロー**  
1. 利用者が自分のプロフィール画面で編集ボタンを押す
2. プロフィール編集画面で自己紹介・アイコン画像を入力・変更する
3. 保存操作を行う
4. システムは利用者情報をDBに反映する

**事後条件**  
プロフィール（アイコン・自己紹介）が更新され、プロフィール画面に反映されている

**例外フロー**  
自己紹介が160文字を超える、または画像の形式・サイズが条件を満たさない場合は保存しない

### UC09：ユーザーを検索する

**アクター**  
ログイン利用者

**事前条件**  
ログイン済みである

**基本フロー**  
1. 利用者が検索画面でキーワード（ユーザー名または表示名）を入力する
2. システムは該当する利用者を検索し、一覧表示する
3. 利用者が一覧から対象を選ぶと、そのプロフィール画面に遷移する

**事後条件**  
検索結果が表示されている

**例外フロー**  
キーワードが未入力の場合は検索を実行しない。該当する利用者がいない場合はその旨を表示する
