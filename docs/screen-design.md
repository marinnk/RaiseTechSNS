# 画面設計：RaiseTechSNS（仮称）

[← 要件定義書に戻る](requirements.md)

## 画面一覧

- S01 ログイン画面：メールアドレス・パスワードでログインする。未ログイン時の起点となる画面
- S02 新規登録画面：ユーザー名・メールアドレス・パスワードで会員登録する
- S03 タイムライン画面：フォロー中の利用者（および自分自身）の投稿を一覧表示し、投稿フォームから新規投稿できる、ログイン後のメイン画面
- S04 投稿詳細画面：1件の投稿とそのコメント一覧を表示し、コメントを投稿できる
- S05 プロフィール画面：利用者の投稿一覧、フォロー中・フォロワー数を表示し、他の利用者の場合はフォロー・フォロー解除ができる

## 画面遷移

- ログイン画面 ⇔ 新規登録画面（未ログイン時に相互に遷移可能）
- ログイン画面 → タイムライン画面（ログイン成功時）
- 新規登録画面 → タイムライン画面（登録成功時）
- タイムライン画面 → 投稿詳細画面（投稿をクリック）
- タイムライン画面 → プロフィール画面（利用者名・アイコンをクリック）
- 投稿詳細画面 → プロフィール画面（投稿者名・アイコンをクリック）
- プロフィール画面 → 投稿詳細画面（投稿をクリック）
- タイムライン画面・投稿詳細画面・プロフィール画面 → ログイン画面（ログアウト操作）

|                                 |
|  アカウントをお持ちでない方は     |
|  [新規登録はこちら]              |
+--------------------------------+
```

```

### タイムライン画面

```
+------------------------------------------------------+
| RaiseTechSNS                [プロフィール] [ログアウト]  |
+------------------------------------------------------+
| [アイコン] 今何してる？（280文字まで）                     |
| [_______________________________________]            |
| [画像を選択（最大4枚）]                     [投稿]        |
+------------------------------------------------------+
| [ 全体 ]   フォロー中                                    |
+------------------------------------------------------+
| [アイコン] ユーザーA                        2026-08-10  |
| 投稿本文がここに表示される                              |
| [画像1][画像2][画像3][画像4]                            |
| ♥ いいね 3     💬 コメント 1                            |
+------------------------------------------------------+
| [アイコン] ユーザーB                        2026-08-09  |
| 投稿本文がここに表示される                              |
| ♥ いいね 0     💬 コメント 0                            |
+------------------------------------------------------+
|         （以下、フォロー中の利用者の投稿が新しい順に続く） |
+------------------------------------------------------+
```

- 「全体」「フォロー中」の2つのタブを持つ。「全体」は全利用者の投稿、「フォロー中」はフォロー中の利用者（および自分自身）の投稿のみを、それぞれ新しい順に表示する
- 未フォローの利用者の投稿は「全体」タブでのみ表示され、「フォロー中」タブには表示されない
- 各投稿に、投稿者のアイコン・名前・投稿日時・本文・（あれば）画像（最大4枚、並べて表示）・いいね数・コメント数を表示する
- いいねボタンは、自分がいいね済みの場合は見た目を変える（塗りつぶし等）
- 投稿をクリックすると投稿詳細画面に遷移する
- 投稿者のアイコン・名前をクリックするとプロフィール画面に遷移する

### 投稿詳細画面

```
+------------------------------------------------------+
| ← タイムラインに戻る                                    |
+------------------------------------------------------+
| [アイコン] ユーザーA                        2026-08-10  |
| 投稿本文がここに表示される                              |
| [画像1][画像2][画像3][画像4]                            |
| ♥ いいね 3     💬 コメント 1                            |
+------------------------------------------------------+
| コメント                                                |
|  [アイコン] ユーザーC   コメント本文がここに表示される      |
+------------------------------------------------------+
| [アイコン] コメントを入力                                |
| [_______________________________________]            |
|                                        [コメントする]    |
+------------------------------------------------------+
```

### プロフィール画面

```
+------------------------------------------------------+
| ← タイムラインに戻る                                    |
+------------------------------------------------------+
| [アイコン]  ユーザーA                                    |
|             フォロー中 12   フォロワー 8                  |
|             [ フォローする ]  ※自分の場合はボタンなし      |
+------------------------------------------------------+
| ユーザーAの投稿                                         |
+------------------------------------------------------+
| [アイコン] ユーザーA                        2026-08-10  |
| 投稿本文がここに表示される                              |
| ♥ いいね 3     💬 コメント 1                            |
+------------------------------------------------------+
```

- フォローボタンは、自分以外の利用者のプロフィール画面にのみ表示する。既にフォロー済みの場合は「フォロー中」（押すと解除）と表示する
- 自分自身のプロフィール画面にはフォローボタンを表示しない
